# Yours to Tale

AI-powered platform for creating, personalizing, and listening to fairy tales.

> 🚧 Early development

## Repository structure

- `apps/web`: Nuxt 4 web application.
- `packages/shared`: Shared TypeScript domain logic and types.
- `services/tts`: Python service for text-to-speech (Qwen3-TTS).
- `infra/terraform`: Infrastructure as Code for Google Cloud/Firebase.
- `docs`: Architecture and product documentation.
